# ミラーフォーカス

メイクやヘアセットをしやすくする、前面カメラ用のiOS鏡アプリです。

## App Storeメタデータ

- アプリ名：ミラーフォーカス
- サブタイトル：拡大できるメイク鏡・手鏡

## 機能

- 左右反転のオン／オフ
- ピンチ操作で1〜4倍の拡大
- 「全体・左目・右目・鼻・口」ごとの拡大表示
- 白色スクリーンライトのオン／オフ
- 顔が暗くならない明るめの自動露出補正
- 映像をタップして瞬時に静止／再開
- 0.3秒押し続けると録画を開始し、長押し中だけ録画（短いタップは静止操作）
- 録画直後の再生確認
- 確認後の録画ファイルを自動削除
- 画面最下部の高さ50ptバナー広告
- UMPによる広告同意の確認

## 実行方法

1. `MirrorFocus.xcodeproj` をXcodeで開きます。
2. 実機のiPhoneを選び、Signing & Capabilitiesで開発チームを確認します。
3. Runします。初回のみカメラ・マイクの利用許可が表示されます。

カメラはiOS Simulatorでは利用できないため、鏡と録画の確認には実機が必要です。対応OSはiOS 17以降です。

## 広告設定

開発中はGoogle公式のテスト広告IDを使用しています。本番公開前に、`Config/Info.plist` の `GADApplicationIdentifier` と `MirrorFocus/Ads/AdConfiguration.swift` の `bannerUnitID` をAdMobで発行したIDへ変更してください。

本番用のAdMobアプリIDへ変更した後、AdMob管理画面の「プライバシーとメッセージ」で同意メッセージを作成・公開してください。アプリは毎回の起動時に同意状態を更新し、広告をリクエストできる状態になってから広告を表示します。
